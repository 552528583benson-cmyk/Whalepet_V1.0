WhalePet 小鲸桌宠 · 朋友分享版 2026-09-20
适用于 Windows x64；自带运行环境，无需安装 Node.js 或购买 API。

【开始使用】
1. 先完整解压 ZIP，不要直接在压缩包内运行。
2. 双击“安装 WhalePet.exe”。程序会复制到本机应用目录，并创建带小鲸头像的桌面快捷方式。
3. 以后双击桌面 WhalePet 图标启动。若已有旧版，请先右键退出旧版再安装。
4. 安装后可删除下载的 ZIP 和解压目录，桌面图标仍然可用。

【和小鲸互动】
- 拖动：拎住短尾巴倒挂，左右移动会产生惯性摆动；松手回到站姿。
- 单击：可爱的小反应。
- 右键 → 小鲸的控制室：调整大小、更换各姿势图片、显示标签、微动作、AI 接入。
- Ctrl + Alt + W：移回安全角落。
- Ctrl + Alt + H：隐藏 / 显示。
- Ctrl + Alt + P：切换状态来源。
- 退出：右键菜单 → 退出。

【AI 状态说明——重要】
普通桌宠不需要联网或登录。默认自动跟随“本机 Codex”新增任务事件。
这不等于自动跟随 ChatGPT 网页、普通 ChatGPT 桌面客户端或所有其他 AI。
其他 AI 需要接入本机状态桥：右键 → 小鲸的控制室 → AI 接入。
改变 AI 名称只会改变标签，不会自动建立连接。没有接入时可手动预览姿势。
本机 Codex 跟随可在右键菜单中关闭；它是基于本地事件记录的尽力兼容适配。
详细说明在 resources\app\PROVIDER_INTEGRATION.md。

【这一版包含】
高清姿势、短尾倒挂、自然呼吸、快速甩动惯性、小尺寸稳定显示、连续快速拖放落点修复。
未打包作者的聊天记录、运行状态、个人设置、测试截图、旧素材、抠图模型或开发依赖。
新安装使用默认设置；覆盖安装保留本机已有偏好。

【安全与卸载】
这是没有购买代码签名证书的个人作品。Windows 可能提示未知发布者。
仅在确认文件来自信任的人后运行；不要为了运行桌宠而关闭系统安全保护。
安装不需要管理员权限，也不会设置开机自启。
卸载：先退出小鲸，再删除桌面快捷方式和 %LOCALAPPDATA%\WhalePet\v0.15。
程序个人数据可能位于 %APPDATA%\whalepet-desktop；仅在确认不再需要偏好时删除。
