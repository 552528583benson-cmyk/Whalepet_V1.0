# 小鲸也会陪你做事

适用于 2026-10-03 本地开发版；旧的 2026-09-30 分享包尚未包含此功能。

## 怎么开启

右键小鲸 → **小鲸的控制室 → 陪伴与操作**。2026-10-04 起右键只留常用的一层菜单，陪伴设置统一在此页，不再有子菜单。

2026-10-05 起已移除“鼠标穿透”开关和 `Ctrl+Alt+L`，旧版本保存的穿透设置会自动清除。小鲸本体始终可点击、拖动和右键，透明留白仍让点击落到后方应用。隐藏改成躲猫猫：她小跑到当前屏幕下沿，只露呆毛；点呆毛探头、再点脑袋缩回；右键“找回小鲸”让她跳回原位。躲着没有 AI 信息，探头只有任务泡泡，两个阶段都暂停陪伴检测和音乐。右键包含直接调整大小的入口，最多 7 项。

1. **先看看**：点“看她敲敲小键盘”，演示约 3 秒，不开启输入检测。
2. **陪我敲键盘**：自行开启后，你按键时她也敲小键盘；停止输入后约 1.2 秒收起来。默认关闭，开关保存在本机。
3. **现在陪我玩游戏**：手动模式只持续到本次关闭或退出，不读取前台游戏，也不需要开启键盘检测。可在控制室随时结束。
4. **自动陪玩**：添加游戏本体的 `.exe`，再开启“跟随我选的游戏”。只在该程序位于前台时握手柄；切回别的应用就结束。添加文件不会启动游戏，不保存完整路径，也不猜测全屏应用就是游戏。最多 32 个游戏，可逐个移除。

陪玩优先于输入陪伴。两种自动检测可以分别关闭；开启陪玩并不会顺便开启键盘检测。

## 她仍然会认真提醒你

陪伴是身体姿势覆盖层，不会伪造 AI 的运行状态，也不改会话名称、任务气泡、状态文件。需要回答、遇到问题和完成庆祝优先显示；手动动作预览、拎尾拖动和歌曲姿势也优先。结束后恢复仍然有效的陪伴或 AI 姿势。

隐藏小鲸、锁屏、休眠会停止自动检测；显示或解锁后，仅重新开启你已勾选的功能，不重放旧的输入活动。陪伴活动期间暂停自动唱歌，避免游戏或输入时突然开唱；已经保存的音乐开关不会被关闭。手动陪玩仍开启时，试听歌曲需先结束陪玩。

## 隐私和限制

检测仅在 Windows 本机运行，不需要管理员权限、网络或付费服务。键盘检测使用短周期轮询，只向小鲸主进程发送按键次数和“有无按住”的临时汇总；不解码字符，不保存按键代码，不记输入文本，不写活动日志。游戏检测仅比较你选定的程序名，不读取窗口标题、网页内容或未选中应用的名称到小鲸界面。诊断只显示陪伴模式、开关和检测器是否可用，不提供按键记录。

普通按键可能在两次轮询之间完成而被漏掉，因此这是陪伴动画，不是精确录制器。受保护、提权或非活动桌面的输入 / 前台查询可能不可用；不会请求提权绕过。独占全屏游戏也可能挡住普通桌面窗口，推荐无边框窗口模式，或关闭陪伴。检测器退出或失联时停止自动姿势并在控制室提示；手动陪玩仍可使用。

Windows API 边界参考：[GetAsyncKeyState](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getasynckeystate)、[GetForegroundWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getforegroundwindow)、[GetWindowThreadProcessId](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getwindowthreadprocessid)。

## 画面和验证

新增素材在 `assets/whalepet-buddy/`。以原作 `assets/whalepet-hd/idle.png` 为参考，通过内置图像生成编辑工具制作；风格库的“角色设定表”模板提供一致性约束，保留蓝发、白发箍、呆毛、短腿和服装，不从其他桌宠复制。两张图均保留生成器的真实透明像素，提示词见 [PROMPTS.md](../assets/whalepet-buddy/PROMPTS.md)。

局部手部变形在 1280 像素源画面计算，再平滑缩至屏幕实际像素大小；身体不呼吸缩放、不旋转、不来回移动，减少小尺寸边缘闪烁。“减少动态效果”系统设置下手部保持静止。图形上下文不可用时继续显示原有 AI 姿势，不阻断状态同步。

测试：`npm run test:buddy`。单元测试覆盖检测器的隐藏生命周期、仅汇总协议、游戏名单过滤、失联恢复、模式优先级和连续手部节奏；隔离的 Electron 测试使用模拟活动，不读取真实键盘或前台应用，验证 UI、紧急覆盖、停止恢复与小尺寸画面。原有陪伴控制、音乐和多任务测试继续保留。
