小鲸鱼桌宠：接入 Live2D 前的源码检查点
2026-10-14（香港时间）

目的
保存当前小鲸鱼的已有功能，再开始独立的 Cubism 眨眼接入。
本检查点没有添加 Cubism SDK/Core，也没有替换目前安装的桌宠。
没有发布新安装包；GitHub 旧 Release ZIP 不会因源码提交自动更新。

来源
使用当前开发源码、运行素材、测试、构建工具和项目文档。
main.js、recovery.js、docs/USER_GUIDE.md 使用当前安装版中最新的文件：
它们包含后来加入的“探头状态也能从脸部拖出”功能，避免备份回退这个功能。
开发 package.json 版本为 0.15.2；现有安装版的 package.json 仍标记 0.15.1。
保留开发版 manifest 及 npm 测试命令，不据此宣称生成了新的安装版。

排除项
运行状态、个人设置、窗口位置、导入音频/自定义图片、聊天日志、备份、临时输出、
下载依赖、模型环境、私人歌曲、连接令牌与 Cubism MCP 配置均不上传。
未批量复制全部原画/候选素材目录，只复制当前运行需要的角色图与部分测试用图。
仓库原有公共历史文件保留；不删除用户已有 GitHub 内容。
既有署名和许可说明保留，不新增针对整个角色或项目的 blanket MIT 许可。

测试范围
执行 JavaScript 语法检查与选定的非图形单元检查，另见上传前核对结果。
这不是完整测试套件通过的声明。
旧 peek-renderer-runtime / peek-pull-runtime 仍有拒绝脸部拖拽的过时断言；
安装版已允许脸部拖拽，后续接入时需要同步测试预期。
历史素材测试还依赖部分已退役素材；当前运行素材与历史制作/测试素材不相同。

后续接入范围
先只为固定的小鲸鱼模型添加待机眨眼。
原有工作姿势、求助/错误优先、泡泡、拖拽惯性、隐藏/探头、歌曲和自定义图片应保留。
SDK/Core 仅用于本地测试，不在这个检查点公开上传。
