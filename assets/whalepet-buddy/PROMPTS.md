# WhalePet companionship sprites

Built-in image generation. Style-library template: Character Design Sheet / 角色设定表 (`character-design-sheet`), adapted as a single pose with the existing character as identity reference. No third-party pet assets.

## Keyboard

用途：identity-preserve，独立 Windows 桌宠透明精灵，单张完整角色。参考图为我们原来的小鲸，只改变动作，不重新设计角色。她坐着，面前/腿上放一块小巧深蓝机械键盘，两只穿原来袖子的手自然放在键盘左右区域，准备交替敲击。憨憨认真又可爱，小嘴轻轻抿着，仍保留原图的二维动漫 Q 版线条、蓝色长发和浅蓝发梢、大蓝眼睛、完整白色荷叶边发箍及黑色结构线、蓝色蝴蝶结、围裙鲸鱼图案、金色裙摆图案、完整蓝色呆毛、唯一的短鲸尾。两条短腿和两只鞋都要露出来。全身正面轻微俯视，与原图同样头部尺度和脸型；四周留透明空隙。键盘不是电脑屏幕，无桌子、椅子、房间、耳机、文字、品牌、水印、发光特效。真正透明背景，发箍、呆毛和发丝之间的空洞均透明，不要把白色背景误当发箍，也不要棋盘格像素。
