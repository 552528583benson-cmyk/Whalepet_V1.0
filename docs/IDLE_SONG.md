# 小鲸的摸鱼小曲

右键小鲸打开「小鲸的控制室」，在音乐设置中导入本地 MP3 / WAV / M4A / OGG 或内嵌音频的 LetMeGo HTML（不超过 30 MB、10 分钟）。导入不会自动开启唱歌，保留原有开关状态。默认音量 18%，1.8 秒淡入，不改变系统音量。可以试听、停止，或随时关闭。

## 防尴尬控制与听歌 CG

- 右键「关闭自动唱歌」或取消「允许待机偷偷唱歌」：立即停止并保存关闭状态。
- 关闭后，同一菜单位置会变成「开启自动唱歌」；点击可重新启用并重新等待 5 分钟，不会立即出声。桌面右键、探头/呆毛右键及托盘菜单使用同一个开关，状态与控制室同步。
- 控制室「安静模式 · 停止并关闭自动唱歌」：作用相同。重启或换歌不会自行重新启用；需要用户明确打开开关。
- `Ctrl+Alt+M`：紧急停止并关闭自动唱歌，不是开关切换，重复按不会重新开启。若快捷键被其他程序占用，设置页会明确提示使用右键菜单。
- 「只停这一首」和永久关闭是不同的操作；前者未来的新一轮待机仍可触发。
- 新用户默认关闭；已经主动启用的用户保留原选择。手动「试听（会出声）」属于显式播放，即使自动唱歌关闭也可使用。
- 播放时显示手持两支粉色荧光棒的专属姿势并持续摇摆；停止或错误时恢复正常姿势。舞步由音频时钟驱动，不是歌曲节拍分析或独立手臂骨骼动画。75% 等小尺寸使用连续平移、不旋转或反复缩放；系统减少动态效果时显示静态图。不会伪造 AI 工作状态。

默认模式：已接入的 GPT 连续待机 5 分钟后播放一次，期间可以正常操作电脑。GPT 开始工作就停止；点小鲸也能停止。待机由主进程工作状态与桌宠已回到 idle 姿势共同确认，动作预览不能把忙碌的 GPT 伪装成待机。不读取普通 ChatGPT 网页，需要本机 Codex 跟随或状态桥接入。

多任务时，只要监听中仍有未结束任务（包括未展示的任务和“状态待确认”），就不开始 AI 待机倒计时。此保护不改变主动试听或另选电脑 / 小鲸静置模式的含义。

另提供电脑模式（整台电脑没有键鼠操作）和小鲸模式（没有点击或拖动小鲸）。这些是可选项，不是用户要求的默认触发条件。

播放结束或失败不会在同一轮静置反复重播。GPT 从忙碌重新进入待机会开始新一轮。启动、恢复、解锁、重新启用、更换歌曲/模式/音量均重新等待。点击小鲸停止并重新等待 5 分钟。设置中的停止按钮只停止本轮，不立即重播。锁屏、休眠、隐藏、拖动时不自动播放。单曲最多播放 10 分钟。手动试听不受电脑键鼠操作打断，但锁屏、休眠、隐藏和点击小鲸仍会停止。

程序只查询系统空闲秒数，不记录按键内容。音频在本机 runtime/custom-audio 中留存副本；旧的成功导入文件保留，不自动删除。无效导入只清除当次创建的失败副本，保留之前的歌曲。恢复默认外观不会改变歌曲设置。

## 用户选定的歌曲

[《LetMeGo》肥鱼摸鱼曲 PV](https://www.bilibili.com/video/BV1pue56AEyL/) 是最初的选曲灵感，安装包不附带该歌曲。导入器支持 audio-b64 / text/plain 内嵌音频的 HTML 源文件，只提取音频字节，不运行 JavaScript、不加载网络资源、不改变原文件。不提供从 B 站下载音频的功能。

歌曲只进入个人运行目录，不加入 assets。分享程序时不要把个人 runtime/custom-audio、preferences.json 或其他运行数据一起打包；若要分发歌曲，先确认允许分享的范围。不能仅凭文件名认定内嵌歌曲与 B 站版本逐字节一致。

## 验证

`npm run test:idle-song`：纯逻辑边界测试 + 独立 Electron 测试配置。后者用程序生成的静音 PCM 验证真实解码和播放，不拿测试样本冒充指定歌曲。测试时钟模拟 299 / 300 秒，无需等待五分钟。

系统空闲检测使用 [Electron powerMonitor](https://www.electronjs.org/docs/latest/api/power-monitor)；导入文件由 Chromium 解码检查，失败不会替换现有歌曲。

## 测试边界

五分钟门槛通过模拟时钟验证；测试播放使用隔离实例并静音，不代表人工听音验收。每位用户的导入音频仍需自行试听。安装包不包含开发者的本机接入路径、个人音频或偏好。
