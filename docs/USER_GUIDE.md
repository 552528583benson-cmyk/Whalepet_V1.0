# 小鲸鱼桌宠使用指南

适用于 0.15.2 / 2026-09-30，Windows x64。

## 安装与更新

从 GitHub Releases 下载 `WhalePet-Friends-20260930.zip`，完整解压，再双击“安装 WhalePet.exe”。不要下载 Source code ZIP 代替安装包。程序自带运行环境，不需要 Node.js 或 API 密钥。

更新前先右键退出旧版；覆盖安装保留本机偏好、导入图片和歌曲。安装器会创建桌面快捷方式，不设置开机自启，也不需要管理员权限。未签名作品可能被 Windows 提醒未知发布者，请核实来源，不要关闭系统保护。

## 控制室

右键小鲸 → 小鲸的控制室。

- **大小**：65%–150%，每步 1%；可直接输入数值，按回车或离开输入框保存。
- **任务泡泡**：随小鲸同比缩放，还能单独调相对大小 80%–120%、上下位置。只还原泡泡不会改变图片或小鲸大小；隐藏后仍保留调节值。
- **姿势图片**：为 12 个工作状态分别导入 PNG / WebP。图片需自带透明背景，不自动抠图；导入副本只存在本机，原作可恢复。导入工作姿势不会替换音乐或倒挂图。
- **窗口**：可调整大小，最小 560 × 480；窄窗口自动单列、内容区滚动。
- **恢复默认外观**：需确认，不重置 AI 或音乐设置、不删除导入文件。

## 多任务状态

仅自动跟随本机 Codex 日志，不自动监控普通 ChatGPT 网页或客户端。其他 AI 需通过本地状态桥发送事件；改名字不等于连接。

优先显示需要回答、遇到问题，然后是完成庆祝、正在工作、待确认任务。最多两张独立标题泡泡；其余任务显示数量。圆点标记当前主姿势来自哪个任务。完成泡泡变绿约 3 秒后消失，小鲸继续跟随其他工作；全部结束时不显示任务泡泡。

普通任务 15 分钟无新事件会显示“状态待确认”，不当作完成，也不会触发 AI 待机唱歌。求助 / 错误超过 24 小时也会标记待确认，仍保持紧急优先级。

### 姿势卡住怎么办？

右键 → **重新读取 Codex 状态**，或控制室 → **AI 接入** → 同名按钮。重读本地记录、重建缓存、退出本地预览并同步姿势，不重启小鲸、不修改对话。失败会保留原状态；如果日志仍等待回答，提醒不会被强制清除。“更新显示”仅刷新控制室读数。

刷新入口仅在选择 ChatGPT / Codex 且开启自动跟随时可用。重启 / 重载只检查最近 24 小时有修改的日志尾部，每份最多 256 KiB，不能保证恢复更早或未被记录的事件。详见 [状态接入说明](../PROVIDER_INTEGRATION.md)。

## 摸鱼小曲

默认关闭且**不附带歌曲**。在“摸鱼小曲”导入本地音频，确认音量后自行开启。GPT 连续待机 5 分钟时播放一次，小鲸拿粉色双荧光棒持续摇摆；GPT 开始工作就停。未结束或待确认的已观察任务会阻止 AI 待机计时。75% 等小尺寸采用连续平移、不旋转、不重复缩放。

开会或上课前使用右键“关闭自动唱歌”或控制室“安静模式”，关闭会持久保存；“只停这一首”不会永久禁用。手动试听会出声。Ctrl+Alt+M 只有成功注册时才可用，被占用时请用右键。详见 [音乐说明](IDLE_SONG.md)。

## 常用操作与隐私

拖动会拎短尾倒挂并产生惯性；松手恢复当前状态。Ctrl+Alt+W 移回安全角落，Ctrl+Alt+H 隐藏 / 显示，Ctrl+Alt+P 切换状态来源。

状态适配读取本地任务事件和标题，不上传聊天内容，不读取登录凭据。分享包不包含作者对话、个人偏好、歌曲、测试截图、模型或开发缓存。
