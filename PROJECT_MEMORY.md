## Fixed scope

- This is a desktop app, not a DeepSeek Harness web plugin.
- States: `idle`, `reading`, `searching`, `working`, `needs_input`, `ready`, `blocked`.
- The released desktop pet works fully locally, without paid APIs or runtime network calls. Asset preparation may use explicitly approved original image generation and free local open-source tooling.
- The 17 key poses are mechanically extracted from the user's movement design sheet.
- Version 0.4 adds 36 generated in-between frames across three transitions, using both supplied design sheets as references; version 0.5 adds an eight-frame cute dragging loop.
- Initial extraction used no semantic vision. After explicit user permission, a visual QA pass corrected crop boundaries, transparent RGB bleed and UI colors; the corrections remain reproducible as code.

## Run and control

- Start: double-click `Start-WhalePet-Desktop.cmd`.
- Move: drag the character.
- React: single-click the character; use Shift + click or the right-click menu to preview states.
- Quit: right-click, then choose `退出 WhalePet`.
- External state bridge:

  `node set-whalepet-state.js working "正在处理文件"`

Any local agent can run that command. WhalePet watches `runtime/state.json` and updates by itself.

## Stability rules

- Duplicate state writes update text without restarting animation.
- Work states have a 2.5-second sticky window across short idle gaps.
- Supported work-state changes use genuine 83ms frames (about 12 FPS), with no crossfade between generated frames.
- Unsupported state pairs retain compress/swap/spring motion hiding; key-pose steps use a short tuck-and-spring swap without overlapping silhouettes.
- All 17 design frames use measured per-frame foot offsets so their ground baseline stays stable.
- Each layer has a request token; stale image-load callbacks cannot reveal an older scene after a rapid state change.
- Ready is a transient celebration and returns to idle after 5.2 seconds.
- Drag position persists in `runtime/window-state.json`.
- The OS window ignores mouse input over transparent pixels. Only opaque character pixels are interactive; the speech bubble and badge are visual-only and cannot start a drag.
- Click reactions have a 650ms cooldown and use compositor animation without forced layout.
- Speech bubbles auto-hide to reduce screen obstruction.
- The default 300×342 window uses a responsive compact layout; it does not rely on page zoom.
- `Ctrl+Alt+W` rescues the pet to a safe corner and `Ctrl+Alt+H` toggles visibility globally.
- The post-drag interaction hold is 180ms; leaving opaque character pixels returns the rest of the window to click-through after 90ms.
- Every pointer press has a matching native drag reset, including ordinary clicks; this prevents stale cursor state from degrading later drags.
- Dragging temporarily overrides only the visible artwork with the hands-up/dangling-feet posture, then restores the active work state on release.
