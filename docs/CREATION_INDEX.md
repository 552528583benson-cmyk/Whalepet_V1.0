# 小鲸鱼桌宠：制作指南与成长记录

## 想制作自己的角色？从这里开始

1. 阅读 [从零制作你的小鲸鱼桌宠](MAKE_YOUR_OWN_WHALEPET.md)：不写代码的导入路线，以及制作独立分享包的源码路线。
2. 复制 [制作与发布验收单](CREATOR_CHECKLIST.md)，记录自己的素材与测试结果。
3. 需要 AI 状态接入时阅读 [状态桥说明](../PROVIDER_INTEGRATION.md)。

当前有效基线：12 张 1280px 默认姿势、单张倒挂图、固定透明画布、时间驱动惯性、小尺寸稳定模式。设置导入器仍使用自己的 384px 归一化流程，不等于默认高清素材管线。

## 她是怎样被做出来的

| 阶段 | 我们做过什么 | 留下的经验 |
| --- | --- | --- |
| 角色与动作设定 | 从用户确认的设计图开始，尝试提取多种工作姿势 | 先固定母版与比例，不靠不停换角色解决细节问题 |
| 透明背景反复修复 | 从阈值与连通区域清理，尝试本地动漫模型，再局部检查与恢复 | 背景白与衣物白不能只靠颜色一刀切；模型也会犯错 |
| 原创姿势统一 | 以认可的角色母版制作不同状态 | 学其他项目的工程方法，不用其他桌宠的角色代替自己的设计 |
| 动作方案收敛 | 放弃会改变发箍、尾巴与体型的整身补间，采用完整姿势与合成器动作 | 身体完整、比例稳定，比帧数多更重要 |
| 高清重建 | 逐张参考原动作与母版制作 12 个高清姿势，再统一画布 | 高清重建不是无损恢复，更不是“放大文件”就完成 |
| 倒挂与微动作 | 保留单张拎短尾倒挂图，局部眨眼/摆尾，加入呼吸与惯性 | 同一张完整图配合连续运动，能减少逐帧造型漂移 |
| 真实桌面验证 | 修复 75% 细线闪烁、呼吸节奏、摆幅限制和快速松手偏移 | 大图预览正确，不代表小尺寸与快速操作也稳定 |
| 朋友分享 | 精简源码和运行包，验证安装器、图标、姿势与状态桥 | 只分享运行必需内容，不把个人状态和开发缓存打包 |

### 不应再照搬的旧做法

- 17 张旧动作表与旧 8 帧拖动循环不是当前运行素材清单。
- 旧版 384px 的修复矩形与采样点不能直接用于 1280px 图片。
- 不能按所有白色像素删除背景，也不能用一个矩形抹去整片头顶。
- 不再为了拖动来回改变透明窗口大小。
- 固定 ±22° 摆幅限制已经取消；数值保护与阻尼仍保留。

## 2026-09-30：多任务与音乐

新增粉色双荧光棒音乐姿势和音频时钟驱动的整体舞蹈；小尺寸通过连续平移减少跳动。多任务跟随强调求助优先、完成后退场和未知状态不冒充结束。控制室加入细粒度尺寸 / 泡泡调节和状态重载。使用与限制见 [使用指南](USER_GUIDE.md)、[音乐说明](IDLE_SONG.md) 和 [本次更新](RELEASE-20260930.md)。歌曲与个人数据不随发布分发。

## 教程整理的边界

教程依据代码与保留记录编写；早期 rembg 与 Alpha 模式说明曾核对官方文档。本次发布同步现有功能、源码和分享包，没有重新生成角色或重新运行抠图模型。

文档中给出的是可执行的制作路线与验收方法，而不是保证任意角色一键变成完美桌宠。
